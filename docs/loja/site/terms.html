1. What KeyFlow Does

KeyFlow is an Android keyboard (Input Method Editor — IME) engineered for typing performance, privacy, and ease of use. Key features include:

  • Canvas Keyboard: High-performance rendering engine with multi-language support (English, Portuguese, Spanish), dynamic accentuation, and on-device spell check powered by static built-in dictionaries.
  • On-Demand Voice Dictation: Audio recording activated strictly when you deliberately tap the dictation button (on the keyboard or the floating overlay orb), transcribing your speech into text.
  • Local and Cloud AI Options: Fully offline neural transcription and language models running on your device, or optional cloud integration using your personal API keys and subscription accounts.
  • Visual Customization: Built-in keyboard themes and support for importing custom theme packs.
