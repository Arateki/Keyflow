# 2026-10-29 — Release mostra todos os modelos (equipe/modelos-sem-trava-debug)

Decisão do Yan: o build release que vai da `main` para os aparelhos dele mostra todo o catálogo, como o debug; ele testa e remove depois o que não funcionar (não é para a loja agora). `ModelCatalog.visibleIn`, `VISION_PROVEN_IDS` e o parâmetro `debug` de `visionModels` saíram; `TEXT`, `VISION`, `VOICE` e `visionModels()` listam tudo. O campo `ModelSpec.validatedOnDevice` ficou só como informação (a Docs e a licença do OCR o usam para não prometer o que não foi visto) e não esconde nada. Antes da loja, a trava volta como decisão explícita, não como estado intermediário "só em debug". Sobrou uma trava de debug fora do escopo: `BuildConfig.AGENT_ENABLED` (o agente com ferramentas) segue só no debug.
